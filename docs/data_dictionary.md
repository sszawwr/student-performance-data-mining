# Data Dictionary (kolom utama)

Dataset matematika UCI Student Performance menggunakan beberapa fitur berikut.

| Kolom | Penjelasan |
|---|---|
| `studytime` | Kategori waktu belajar mingguan (1 sampai 4) |
| `failures` | Kode jumlah kegagalan kelas sebelumnya |
| `absences` | Jumlah ketidakhadiran |
| `schoolsup` | Dukungan pendidikan tambahan dari sekolah (yes/no) |
| `G1` | Nilai periode pertama |
| `G2` | Nilai periode kedua |
| `G3` | Nilai akhir; target regresi (0 sampai 20) |

Dataset juga memiliki atribut demografis, keluarga, sosial, dan sekolah. Lihat dokumentasi UCI untuk definisi lengkap setiap kolom.
