# Dataset

Dataset yang digunakan: **UCI Student Performance**  
Sumber resmi: https://archive.ics.uci.edu/dataset/320/student+performance

Pipeline akan mengunduh arsip publik dari UCI bila data lokal belum tersedia. File matematika `student-mat.csv` digunakan sebagai dataset utama dan dibaca dengan pemisah titik koma (`;`).

Jika unduhan otomatis gagal, unduh arsip dataset dari halaman UCI, lalu letakkan `student-mat.csv` di folder `data/raw/`.

Data mentah tidak di-commit ke GitHub; periksa ketentuan sumber sebelum redistribusi.
